COURSE OVERVIEW

Build Web Applications with Django

Django is a high-level Python web framework designed to help developers build secure and maintainable web applications efficiently. It follows the Model-Template-View architecture and encourages reusable and organized code.

Our Django classes introduce students to web development using Python, covering Django fundamentals, URL routing, templates, models, forms, authentication, databases, and practical application development.
